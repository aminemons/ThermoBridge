## Technical findings

The existing RTL integral increment is rounded into whole Q8 duty counts on each sample. With the frozen coefficient `KI=4`, a temperature error of 1 C produces `round_even(4*64/4096)=0`. Thus small residual errors cannot accumulate into integral action. This is a configuration-level quantization issue; it can be studied with larger supported integral coefficients without modifying the physically implemented RTL. Any new tuning must use a frozen training protocol and preserve the original held-out result.

The spatial solver, archived routed core and original 540-trial campaign are retained. Full PFE status still requires an analogue macro, routed arithmetic alternatives and independent physical/model validation; a professional article must distinguish these from completed prototype evidence.
